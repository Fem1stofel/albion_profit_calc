# Albion Profit Calculator

Калькулятор и анализатор выгодных торговых маршрутов между городами и Черным рынком в Albion Online.

---

## Быстрый запуск

Для запуска приложения на Windows запустите файл `start.bat`. 
Скрипт автоматически создаст виртуальное окружение, установит зависимости, проверит базу данных и запустит сервер.

После запуска:
- Веб-интерфейс: http://localhost:8000
- Документация API (Swagger): http://localhost:8000/docs

---

## База данных

Проект использует локальный PostgreSQL (порт 5432) без контейнеров.

Скрипт `init_db.py` автоматически подготавливает базу данных:
- Если база `albion_profit` уже существует — подключается к ней.
- Если базы нет — создает новую, применяет схему из `init.sql` и загружает справочник предметов из `data/items.json.gz`.

Параметры подключения настраиваются в файле `.env`:
```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=albion_profit
DB_USER=postgres
DB_PASSWORD=123
```

Ручной запуск инициализации базы данных:
```bash
python init_db.py
```

## Тестирование

Для запуска тестов выполните команду:
```bash
pytest test_main.py -v
```

Тесты проверяют корректность формул прибыли, налоги, работу API и подключение к базе данных.

## CI/CD (Jenkins)

Для автоматической проверки проекта настроен `Jenkinsfile`. При запуске пайплайн:
1. Загружает свежий код из репозитория.
2. Устанавливает зависимости.
3. Проверяет и инициализирует базу данных PostgreSQL (без Docker).
4. Запускает тесты с генерацией отчета.
5. Проверяет корректность старта приложения.

Запуск в Jenkins:
1. Создать задачу с типом Pipeline.
2. В блоке Pipeline выбрать "Pipeline script from SCM" -> Git.
3. Указать ссылку на репозиторий и ветку `*/main`.
4. Нажать "Собрать сейчас".
