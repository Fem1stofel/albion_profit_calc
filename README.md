# Albion Profit Calculator 🚀

Калькулятор и анализатор выгодных торговых маршрутов между королевскими городами и Чёрным рынком в Albion Online.

---

## 👤 Для обычного пользователя (Быстрый старт)

Если вы просто хотите пользоваться калькулятором — **никакие Jenkins и Docker вам не нужны**:

1. Запустите файл **`start.bat`** (двойным кликом).
2. Скрипт сам всё настроит:
   - Проверит локальный Python и зависимости.
   - Проверит и подготовит базу данных PostgreSQL (подключит существующую или автоматически создаст новую).
   - Запустит сервер.
3. В браузере автоматически откроется **http://localhost:8000** (API-документация: **http://localhost:8000/docs**).

---

## ❓ Зачем вообще нужен Jenkins (CI/CD)?

### Обычному пользователю он НЕ нужен
Обычный пользователь просто запускает приложение через `start.bat`.

### Зачем он разработчикам и проекту:
**Jenkins** — это сервер автоматизации для команды разработки:
1. **CI (Continuous Integration — Непрерывная интеграция):**
   - При каждом изменении кода или отправке в Git (`git push`) Jenkins автоматически:
     - Разворачивает свежее окружение.
     - Проверяет подключение к PostgreSQL и применяет миграции/схему.
     - Запускает весь набор автоматических тестов (**33 теста**).
   - Если разработчик случайно ошибся в формуле налога, сломал API или забыл импорт — Jenkins мгновенно сигнализирует об ошибке («красный пайплайн»), не допуская попадания бага в релиз.
2. **CD (Continuous Delivery / Deployment — Непрерывная доставка):**
   - Если все тесты зелёные, Jenkins может автоматически собрать дистрибутив или перезапустить рабочую версию сервера на хосте.

## 🗄️ База данных (Без Docker-контейнеров)

База данных работает напрямую в установленном на системе PostgreSQL (по умолчанию порт `5432`):
- За логику отвечает скрипт [`init_db.py`](init_db.py).
- **Если база `albion_profit` уже существует:** скрипт подключается к ней и проверяет актуальность схемы.
- **Если базы нет:** скрипт подключается к серверу PostgreSQL, создаёт новую базу данных `albion_profit`, накатывает структуру из [`init.sql`](init.sql) и импортирует базовый справочник предметов из `data/items.json.gz`.

Ручной запуск инициализации БД:
```bash
python init_db.py
```

Параметры подключения настраиваются в файле `.env`:
```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=albion_profit
DB_USER=postgres
DB_PASSWORD=123
```

## 🧪 Запуск автоматических тестов

В проекте реализован полный набор модульных и интеграционных тестов ([`test_main.py`](test_main.py)):
- Корректность формул расчёта валовой и чистой прибыли, комиссий и ROI.
- Граничные условия (нулевые/отрицательные цены, дробные числа).
- Соответствие идентификаторов и названий городов.
- Кэширование и фолбэк каталога предметов.
- Интеграционная проверка эндпоинтов FastAPI (`/`, `/docs`, `/api/health`, `/api/locations`, `/api/items-catalog`, `/api/scan-progress`).

Запуск тестов:
```bash
pytest test_main.py -v
```

## ⚙️ Структура CI/CD пайплайна (Jenkinsfile)

Пайплайн описан в файле [`Jenkinsfile`](Jenkinsfile) и включает 5 этапов:

```mermaid
flowchart LR
    A[1. Checkout Git] --> B[2. Install Dependencies]
    B --> C["3. DB Setup (No Container)"]
    C --> D[4. Run 33 Tests]
    D --> E[5. Smoke Test App]
    E --> F[JUnit Reports]
```

1. **Checkout:** получение актуального кода из репозитория.
2. **Install Dependencies:** установка пакетов из `requirements.txt`.
3. **Database Setup (No Container):** запуск `init_db.py` без Docker. Подключает готовую БД или создаёт новую.
4. **Run Tests:** запуск `pytest` с сохранением отчёта `test-results.xml`.
5. **Smoke Test App:** проверка корректного старта экземпляра FastAPI.
6. **Post:** сбор результатов тестов в отчёты JUnit Jenkins.

### Подключение в локальном Jenkins:
1. Панель Jenkins доступна по адресу: **http://localhost:8080**
2. Создайте задачу: **New Item** → Имя: `albion-profit-ci` → Тип: **Pipeline**.
3. В настройках: **Pipeline script from SCM** → **Git** → указать путь к репозиторию → ветка `*/main` → Script Path: `Jenkinsfile`.
4. Нажмите **Build Now** для запуска пайплайна.

## 🛠 Стек технологий
- **Backend:** Python 3.11+, FastAPI, Uvicorn, Psycopg2
- **Database:** PostgreSQL (нативный сервер, схема `albion`)
- **Testing:** Pytest, HTTPX, Unittest
- **CI/CD:** Jenkins Pipeline (Groovy, JUnit)
- **Frontend:** HTML5, CSS3, JavaScript
